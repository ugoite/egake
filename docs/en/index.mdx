## Source of truth and checks

The executable specification is <a href="docs/spec/"><code>docs/spec.md</code></a>, and the acceptance workflows are in <a href="docs/usage/"><code>docs/usage.md</code></a>. The site reads the repository `docs/` tree through Starlight’s `docsLoader()` instead of copying page bodies.

```sh
mise run docs:install
mise run docs:check
mise run docs:build
```

<Aside type="tip" title="A promise of this site">
  Commands, filenames, and identifiers in the text exist in this checkout. A
  framework adapter that is not shipped is described as a generic runtime
  boundary, not as a package that can be installed.
</Aside>
