## Choosing a path

| Goal                                | Entry point                   | Checked-out verification                            |
| ----------------------------------- | ----------------------------- | --------------------------------------------------- |
| Build a table from files only       | Standalone CSV                | `cargo run -p egake-cli -- list ...`                |
| Inject your API into a browser host | `packages/runtime`            | `deno test examples/js-embedded/main_test.ts`       |
| Expose an existing Python resource  | `ResourceASGIApp`             | `mise run python:test`                              |
| Reuse a Ugoite client               | `createUgoiteEntriesProvider` | `deno test examples/ugoite-entries/adapter_test.ts` |
| Use the Ikasue UI runtime           | `packages/ikasue`             | `mise run ui:test`                                  |

The [executable MVP specification](../../spec/) contains shared details about queries, errors, merge-patch, and path safety.
