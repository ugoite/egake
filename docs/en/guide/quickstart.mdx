Run these commands from the repository root. `examples/csv-readonly` is checked in and needs no external service, credentials, or Node package.

<Steps>
1. Enable the pinned toolchain.

   ```sh
   mise install
   mise run setup
   ```

2. Validate the example.

   ```sh
   cargo run -p ikashita-cli -- validate examples/csv-readonly
   ```

   This checks `app.ui.kdl`, the schema JSON, `resources.kdl`, and the CSV together.

3. Search and list the CSV. `ada` matches Ada Lovelace’s title.

   ```sh
   cargo run -p ikashita-cli -- list examples/csv-readonly --resource catalog --query ada --sort title
   ```

4. Run the project test and inspect the static bundle.

   ```sh
   cargo run -p ikashita-cli -- test examples/csv-readonly
   cargo run -p ikashita-cli -- build examples/csv-readonly
   ```

   The build writes `index.html`, runtime assets, and `app.bundle.json` to `examples/csv-readonly/dist/`. Do not commit that generated directory.

</Steps>

## What happened?

<Tabs>
  <TabItem label="Definition">

`app.ui.kdl` requires only `list` for the `catalog` resource and asks the `data-table` to display `title`, `category`, and `description`.

  </TabItem>
  <TabItem label="Data">

`resources.kdl` opens `data/catalog.csv` as a read-only provider. Because there is no `id` column, write capabilities are not advertised.

  </TabItem>
  <TabItem label="Output">

`app.bundle.json` contains the validated Application Profile and schema metadata, not CSV records.

  </TabItem>
</Tabs>

<Aside type="note" title="Run again after edits">
  `dev` is no-watch in this MVP. Stop it after editing files and run `cargo run
  -p ikashita-cli -- dev examples/csv-readonly` again.
</Aside>
