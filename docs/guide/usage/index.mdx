## 選び方

| やりたいこと                       | 入口                                   | チェックアウト済みの確認                            |
| ---------------------------------- | -------------------------------------- | --------------------------------------------------- |
| ファイルだけで一覧を作る           | standalone CSV                         | `cargo run -p ikashita-cli -- list ...`             |
| ブラウザhostに自分のAPIを注入する  | `packages/runtime`                     | `deno test examples/js-embedded/main_test.ts`       |
| Pythonの既存resourceを公開する     | `ResourceASGIApp`                      | `mise run python:test`                              |
| Ugoite clientを再利用する          | `createUgoiteEntriesProvider`          | `deno test examples/ugoite-entries/adapter_test.ts` |
| React/VueでVNode/elementを生成する | `packages/react` / `packages/vue`      | `mise run deno:check`                               |
| Solid/Svelteを使う                 | generic runtimeまたは自前の薄いadapter | このcheckoutに専用packageは未提供                   |

共通の細かい仕様（query、error、merge-patch、path safety）は[実行可能なMVP仕様](../../spec/)に集約しています。
