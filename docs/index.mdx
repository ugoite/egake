## 正本と検証

仕様の正本は<a href="docs/spec/"><code>docs/spec.md</code></a>、exampleを横断する受け入れ手順は<a href="docs/usage/"><code>docs/usage.md</code></a>です。サイトは`docs/`へのシンボリックリンクをStarlightの`docsLoader()`で読むだけで、本文ファイルをコピーしません。サイト自体は次のコマンドで検証できます。

```sh
mise run docs:install
mise run docs:check
mise run docs:build
```

  説明に登場するCLI、ファイル名、関数名はこのcheckoutに存在するものだけです。まだ提供していないSolid/Svelte専用パッケージは、汎用runtimeとの境界として正直に扱います。
</Aside>
